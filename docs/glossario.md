# Glossário

ADR
:   Architecture Decision Record. Documento curto que registra uma decisão de arquitetura.

Catálogo
:   Inventário de software do Backstage (componentes, APIs, sistemas, times).

Golden path
:   Caminho recomendado e suportado pela plataforma para construir e operar serviços.

RED
:   Rate, Errors, Duration. Métricas mínimas de um serviço.

SLO
:   Service Level Objective. Meta de confiabilidade, por exemplo "99,9% das requisições < 300 ms".

TechDocs
:   Solução de docs-as-code do Backstage, baseada em MkDocs.
