# ADRs: Architecture Decision Records

Um ADR registra **uma** decisão de arquitetura: o contexto, a decisão e as consequências.

## Onde ficam

- Decisões de um serviço: `docs/adr/` no repo do serviço.
- Decisões transversais: nesta wiki.

## Modelo

```markdown
# ADR NNNN: Título

- **Status:** proposto | aceito | substituído por ADR-XXXX
- **Data:** AAAA-MM-DD

## Contexto
## Decisão
## Consequências
```
